# **App Name**: ApexCalc

## Core Features:

- AI Calculator Creation: Generate calculators using natural language input powered by the Gemini API, serving as a tool to reason when the prompt contains ambiguity. For example, interpret 'mortgage calculator' even when interest rate or duration is missing.
- F1-Themed Interface: Implement a responsive UI with an F1 theme including speedometer-style inputs.
- Anonymous Calculator Access: Allow users to browse and use pre-made calculators without creating an account.

## Style Guidelines:

- Primary color: Bright red (#FF2D00) to capture the speed and excitement of F1 racing.
- Background color: Dark charcoal (#222222) for a sleek, modern dark mode interface.
- Accent color: Neon yellow (#FFFF33) to highlight interactive elements and call-to-actions.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, techy look.
- Body font: 'Inter' (sans-serif) to maintain readability in longer texts
- Incorporate F1-inspired icons representing different calculator types.
- Add smooth transitions and subtle animations that mimic gear shifts and engine revving.
